Frontend client stubs and tests for Authority State Machine (ASM).

Quick start (from `frontend`):

1. Install deps:

```bash
npm ci
```

2. Run tests:

```bash
npm test
```

Notes:
- These are minimal client-side stubs (Electron + React + TypeScript + Redux Toolkit).
- The `TokenRenderer`, `AiClient`, `CouncilClient`, and `authority` slice are provided as architectural-enforcement examples.
